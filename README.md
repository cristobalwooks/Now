# NOW

**NOW** to asystent decyzyjny dla ludzi przeciążonych myśleniem.

W kluczowym momencie mówi:
> *„to jest najlepszy możliwy ruch TERAZ”.*

Nie planuje.  
Nie analizuje w nieskończoność.  
Nie motywuje hasłami.

**Decyduje.**

---

## Problem, który rozwiązuje

NOW nie walczy z lenistwem.  
Walcz y z **paraliżem decyzyjnym**.

Użytkownik:
- ma listę rzeczy do zrobienia,
- ma czas,
- ma energię,

ale **nie potrafi wybrać, od czego zacząć**.

To moment, w którym:
- otwierasz kolejne aplikacje,
- sprawdzasz social media,
- „jeszcze tylko kawka”,
- mija godzina.

NOW wchodzi **dokładnie w tym momencie**.

---

## Dla kogo jest NOW

### Dla overthinkerów
- dużo pomysłów,
- dużo „powinienem”,
- trudność w przejściu do działania.

### Dla osób kreatywnych
- chaos zadań,
- brak sztywnych godzin,
- niechęć do kalendarzy i planów.

### Dla ludzi zmęczonych produktywnością
- nie chcą planować tygodnia,
- nie chcą KPI, streaków ani statystyk,
- chcą po prostu **ruszyć**.

NOW nie mierzy.  
NOW uruchamia.

---

## Czym NOW **nie jest** (to kluczowe)

NOW **nie jest**:
- listą zadań,
- planerem dnia,
- kalendarzem,
- aplikacją motywacyjną,
- systemem GTD.

NOW **nie pyta**:
- „co chcesz zrobić dziś?”  
- „jakie masz priorytety?”

Bo w tym momencie użytkownik **już tego nie wie**.

---

## Jak działa (filozoficznie)

NOW opiera się na jednym założeniu:

> Człowiek nie potrzebuje idealnej decyzji.  
> Potrzebuje **wystarczająco dobrej decyzji TERAZ**.

Dlatego:
- jedno zadanie,
- jeden ruch,
- brak cofania,
- brak rozliczania,
- brak historii sukcesów i porażek.

To nie jest „zrób wszystko”.  
To jest: **„rusz”**.

---

## Dlaczego „ZACZĄŁEM” jest ważniejsze niż „ZROBIONE”

NOW rozumie coś, czego większość aplikacji nie rozumie:

**najtrudniejszy moment to start.**

Dlatego:
- jedyna presja to kliknięcie **„ZACZĄŁEM”**,
- potem presja znika,
- wykonanie może trwać tak długo, jak trzeba.

NOW nie kontroluje.  
NOW odpuszcza.

---

## Status

NOW jest **świadomie minimalistyczny**.

Każda nowa funkcja musi:
- zmniejszać paraliż decyzyjny,
- skracać drogę do działania,
- nie wprowadzać planowania ani kontroli.

Jeśli tego nie robi — **nie trafia do projektu**.
